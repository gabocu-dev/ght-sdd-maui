# Sum Two Number App

A simple mobile app for adding two numbers and viewing the total in a local-only single-screen experience.

## Overview
This project follows the SDD workflow and is built to satisfy the requirement of a straightforward calculator app for general users.

## Features
- Two numeric input fields
- Calculate action
- Result display
- Lightweight local-only experience

## Getting Started
1. Install .NET SDK and MAUI workload support.
2. Open the project in a supported editor.
3. Restore dependencies and run the app on a simulator or device.

## Project Structure
- `src/` — app source
- `tests/` — unit and flow tests
- `specs/001-sum-two-number-app/` — SDD artifacts
