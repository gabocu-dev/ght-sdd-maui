# Contributing

## Development Expectations
- Keep scope aligned to the approved spec.
- Favor small, modular implementations.
- Add tests for calculation correctness and main UI flow.
- Keep configuration externalized and avoid hardcoded secrets.

## Workflow
1. Review the current spec and task list.
2. Implement the smallest valid change for the target task.
3. Validate with the relevant tests and build checks.
4. Keep documentation in sync with behavior changes.
